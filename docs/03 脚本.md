# 脚本 — 案1「呪い」

## 一言で

目を潰された一つ目の巨人が、父である海の神に祈る。「あの男を、家に帰らせるな」。その呪いの一句ごとに、それが現実になっていく絵が続く。呪いの中身が、そのまま『オデュッセイア』全体のあらすじになっている。

## もとになる原作の箇所

第9歌の終わり。巨人ポリュペモスが、船で逃げるオデュッセウスの名を聞いて、海の神ポセイドンに祈る。中身は次の順番:

1. あの男が家に帰り着かないように
2. もし帰り着く定めなら、遅く
3. みじめな姿で
4. 仲間をすべて失って
5. 他人の船で
6. そして家では災いに出会うように

原作では、この祈りのとおりに全部が起きる。

## 時間割（版 0。2026-09-20）

**声の文言は直し中。** 本人の指摘: 日本語としても、予告編の声としても不自然。下の「声」の欄は仮のもので、このまま使わない。絵の並びは本人が選んだ案のまま。

声は英語で話し、日本語は字幕で付ける（本人、2026-09-20）。直した版では「英語の声」と「日本語字幕」の2欄にする。
